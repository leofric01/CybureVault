# CyberVault 🛡️

A modular Python-based cybersecurity toolkit designed for fundamental security checks and utilities.

## 🚀 Features

1. **Password Strength Checker**: Validates password length and security level.
2. **Password Generator**: Generates secure random passwords.
3. **Username Generator**: Creates custom usernames with random prefixes and numbers.
4. **IP Address Validator**: Validates IPv4 address formats.
5. **Port Checker**: Identifies common service ports (SSH, HTTP, HTTPS).
6. **Caesar Cipher**: Encrypts sensitive text or numeric strings.
